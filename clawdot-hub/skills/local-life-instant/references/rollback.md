# 改主意会清掉什么

下单前改前面某一项时，下面这些动作会清掉后面已经选好的东西，清掉的要重新选、重新加；表里没列的动作不清东西。
确认页清掉以后，重新核价，就会出新的。
重选**同一个**地址什么都不清；重选同一家店照样清空购物车（每次选店都是一辆新的购物车）。

## 即时零售

| 想改什么 | 调哪个 | 会清掉 |
|---|---|---|
| 换收货地址 | `instant_address` · `select` | 店、购物车、确认页 |
| 换一家店 | `instant_browse` · `select` | 购物车、确认页 |
| 搜别的店、换货架、翻页、看规格 | `instant_browse` · `search` / `menu` / `item` | 不清 |
| 加一样、改份数、删一样（份数填这件一共几份，设成 0 就是删）、重新核价 | `instant_cart` · `update` / `preview` | 确认页 |
| 列已存地址、搜新地址 | `instant_address` · `search` | 不清 |
